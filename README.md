# Q24 무인 당구장 앱

- 시험 주소: https://q24gogo.github.io/q24/
- 정식 주소(예정): app.q24.co.kr

## 앱 목록

| 앱 | 파일 | 기기 |
|---|---|---|
| 시작 페이지 | `index.html` | 주소만 입력했을 때 |
| 인식기 | `checkin.html` | 입구 태블릿 1대 |
| 현황판 | `board.html` | 벽면 태블릿 2~3대 |
| 점수판 | `score.html` | 테이블마다 태블릿 1대 |
| 업주 | `owner.html` | 업주 폰 |
| 회원 | `member.html` | 손님 폰 |
| AI 테이블 (고급형) | `ai.html` | 테이블마다 PC 1대 (준비 중) |

앱마다 부속 파일: `앱이름.webmanifest`(설치 정보), `앱이름-sw.js`(오프라인 실행), `icons/앱이름-192.png`, `icons/앱이름-512.png`

## 폴더

- `icons/` 아이콘
- `engine/` AI 자동득점 엔진 (점수판 영상 모드가 `engine/3qAutoscore.html`을 사용)

## 업데이트 규칙

- 바뀐 `앱이름.html`만 루트에 덮어쓰기 (부속 파일은 처음 한 번만)
- 각 앱 화면의 버전 표시(v2.xx)로 적용 확인
- **고객 데이터·백업 파일은 절대 이 저장소에 올리지 않음** (공개 저장소)

- **본사 프로그램(hq.html)과 lab(자동득점·코칭 학습 도구)은 이 저장소에 올리지 않음** (본사 PC·관리자 PC에만 보관)
